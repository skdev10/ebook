DigitalOcean App Platform — set these as Environment Variables (nested keys use double underscore).

Required for database & startup:
  ConnectionStrings__DefaultConnection
    Example (managed MySQL): server=YOUR_HOST;port=25060;database=ebookpublications;user=doadmin;password=SECRET;SslMode=Required;
    On App Platform this SECRET overrides appsettings ConnectionStrings:DefaultConnection (appsettings carries a localhost default for the VM).

Security: Rotate any DB password committed in appsettings if the repo is shared or public; prefer secrets + env on production hosts.

Login on plain HTTP (e.g. http://YOUR_DROPLET_IP:5000/ during testing):
  Authentication__CookieSecurePolicy
    Use SameAsRequest (default in appsettings) so auth + session cookies are accepted over HTTP; on HTTPS they become Secure.
    Set to Always only when the app is never served over HTTP — otherwise browsers will not store login cookies and sign-in appears broken.

Bare VM / production-style run (local MySQL); appsettings.Production.json sets UseLocalFallbackConnection=true.
  You must supply credentials (Linux MySQL rarely allows root with no password):
    MYSQL_ROOT_PASSWORD=...   (or MYSQL_PASSWORD=...)
    Optional: MYSQL_HOST MYSQL_PORT MYSQL_DATABASE MYSQL_USER
  Same values work as Docker-style env; alternatively set ConnectionStrings__DefaultConnection (wins everywhere when set).
  App Platform managed DB: use ConnectionStrings__DefaultConnection SECRET only; MYSQL_* unused if connection string present.
  To disable fallback: Database__UseLocalFallbackConnection=false
  Full string override without env pieces: Database__LocalFallbackConnection=server=127.0.0.1;... (single line)

Public URL for Stripe redirects / emails:
  App__PublicBaseUrl
    Example: https://your-app.ondigitalocean.app

Optional payment API (Plans/BuyPlan):
  PaymentApi__BaseUrl

OAuth — REQUIRED on App Platform for Google/Facebook login (if unset, schemes are not registered and users see social_unavailable / icons hidden):
  Authentication__Google__ClientId
  Authentication__Google__ClientSecret
    Web OAuth always needs BOTH; Client ID may also exist in appsettings.json but the secret must never be committed — set via env or dotnet user-secrets locally.
  Authentication__Facebook__AppId
  Authentication__Facebook__AppSecret
    Callback URLs in Google Cloud / Meta apps must match your live site, e.g. https://YOUR_DOMAIN/auth/google/callback and https://YOUR_DOMAIN/signin-facebook

External chapter/cover API:
  ExternalApi__BaseUrl
  ExternalApi__GenerateUrl
  ExternalApi__EditUrl
  ExternalApi__ApproveUrl
  ExternalApi__GenerateCoverUrl
  ExternalApi__EditCoverUrl
  ExternalApi__AudioUrl
  ExternalApi__QueueDataUrl
  ExternalApi__RefineCoverPromptUrl
  ExternalApi__SuggestCoverPromptFromHighlightsUrl
  Optional (default false / omit): ExternalApi__AudioSendLocalFilePath
    Set to "true" only if the audio worker runs on the same machine as this app and can read the saved file path. On App Platform, leave unset so only the uploaded bytes are sent (avoids upstream 500 from invalid paths).

OpenAI:
  OpenAI__ApiKey
    If ExternalApi audio returns 500, this app retries transcription with OpenAI when this key is set (configure both for resilience).

Stripe:
  Stripe__PublishableKey
  Stripe__SecretKey
  Stripe__WebhookSecret
  PaymentSettings__Stripe__PublishableKey
  PaymentSettings__Stripe__SecretKey
  PaymentSettings__Stripe__WebhookSecret
  PaymentSettings__Stripe__BaseUrl

JWT (if used):
  JwtSettings__SecretKey

SMTP:
  Email__SmtpServer
  Email__Username
  Email__Password
  Email__FromEmail

Managed MySQL CA (alternative to mounting file):
  Database__SslCaPem
    PEM content with literal newlines replaced by \n in the env value if required by your platform.

HTTP port on DO App Platform:
  PORT (injected automatically; Program.cs binds http://0.0.0.0:${PORT})

Local development without committing secrets:
  Use User Secrets (dotnet user-secrets set "ConnectionStrings:DefaultConnection" "...")
  or set the same variables in your shell / launch profile.
